# 架构图和产品逻辑图

本目录包含了课程材料 RAG 聊天机器人的完整可视化架构图。所有图表均使用 SVG 格式绘制，可以在浏览器中直接打开查看。

## 📊 图表列表

### 1. 系统架构图 (system_architecture.svg)
**文件**: `system_architecture.svg`

展示了完整的系统架构，包括：
- **前端层**: Web Browser, HTML/CSS/JS, Marked.js
- **API 网关层**: FastAPI + Uvicorn
- **核心业务层**: RAG System, Session Manager, AI Generator, Tool Manager, Document Processor
- **AI 服务层**: Claude Sonnet 4, Tool Calling
- **数据存储层**: Vector Store, ChromaDB, 两个数据集合
- **嵌入服务层**: Sentence Transformers

**适用场景**:
- 理解整体技术栈
- 了解各层之间的关系
- 技术选型参考

---

### 2. 数据流程图 (data_flow.svg)
**文件**: `data_flow.svg`

详细展示了从用户输入到返回答案的完整数据流：
1. 用户输入查询
2. 前端创建/获取 Session
3. API 接收请求
4. 检查会话历史
5. Claude AI 分析
6. 决策是否需要搜索工具
7. 执行语义搜索（如需要）
8. 生成答案
9. 保存会话
10. 返回响应
11. 前端展示

**适用场景**:
- 理解查询处理流程
- 调试问题时追踪数据流
- 性能优化分析

---

### 3. 组件依赖图 (component_dependency.svg)
**文件**: `component_dependency.svg`

展示了所有 Python 模块之间的依赖关系：
- **入口点**: app.py
- **核心模块**: rag_system.py
- **服务模块**: ai_generator.py, vector_store.py, document_processor.py, session_manager.py
- **工具模块**: search_tools.py, config.py
- **数据模型**: models.py
- **外部依赖**: Anthropic API, ChromaDB, Sentence Transformers, FastAPI, Pydantic, python-dotenv

**适用场景**:
- 代码重构参考
- 理解模块职责
- 新功能开发时确定影响范围

---

### 4. 产品逻辑图 (product_logic.svg)
**文件**: `product_logic.svg`

从产品角度展示系统的核心价值和功能：
- **用户层**: 学生/教师的需求、目标、操作、体验
- **界面层**: 聊天界面、侧边栏、消息渲染、交互反馈
- **核心功能层**:
  1. 智能问答（智能对话）
  2. 语义搜索（精准检索）
  3. 来源追溯（可信度）
  4. 工具调用（智能化）
- **AI 处理层**: Claude Sonnet 4, 上下文增强
- **数据层**: 课程文档, 向量数据库, 会话数据
- **输出层**: 智能答案, 来源引用, 会话延续, 用户满意度

**核心价值主张**:
- ✓ **智能化**: AI 驱动的自然语言理解和回答生成
- ✓ **精准性**: 语义搜索找到最相关内容，超越关键词匹配
- ✓ **可信度**: 每个答案都有明确的来源引用，可验证
- ✓ **易用性**: 简洁界面，自然对话，即时响应

**适用场景**:
- 产品介绍和演示
- 理解产品核心价值
- 功能优先级决策

## 🖥️ 如何查看图表

### 方法 1: 浏览器直接打开（推荐）
1. 在文件浏览器中找到 SVG 文件
2. 右键选择"打开方式" → "浏览器"
3. 或者直接拖拽 SVG 文件到浏览器窗口

**支持的浏览器**:
- Chrome / Edge / Safari / Firefox（所有现代浏览器）

### 方法 2: VS Code 预览
1. 在 VS Code 中打开 SVG 文件
2. 右键选择 "Open Preview"
3. 或者安装 "SVG" 扩展获得更好的预览效果

### 方法 3: GitHub 在线查看
如果项目托管在 GitHub，直接在仓库中点击 SVG 文件即可查看。

### 方法 4: 在线 SVG 查看器
访问以下在线工具：
- https://www.svgviewer.dev/
- https://svg-edit.github.io/svgedit/

## 📐 图表特点

### ✨ 高质量矢量图形
- **可缩放**: 无损放大，永不模糊
- **文件小**: 相比 PNG/JPG，文件体积更小
- **可编辑**: 可以用文本编辑器直接编辑 SVG 代码

### 🎨 专业设计
- **色彩编码**: 不同类型的组件使用不同颜色区分
- **清晰标注**: 中英文双语标注
- **层次分明**: 使用分组和背景色区分不同层次
- **连接线**: 箭头清晰标示数据流向和依赖关系

### 📱 响应式
- **自适应**: 在不同屏幕尺寸下都能正常显示
- **可打印**: 适合打印成文档

## 📝 图例说明

### 箭头类型
- **实线箭头**: 直接调用/依赖关系
- **虚线箭头**: 间接依赖（import）
- **粗箭头**: 主数据流
- **彩色箭头**: 决策分支（绿色=是，红色=否）

### 形状含义
- **矩形**: 组件、模块、功能
- **圆角矩形**: 服务、系统
- **椭圆**: 开始/结束节点
- **菱形**: 决策点
